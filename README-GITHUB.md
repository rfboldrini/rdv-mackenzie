# RDV Mackenzie — publicação no GitHub Pages

1. No GitHub, crie um repositório público chamado `rdv-mackenzie`.
2. Clique em **Add file > Upload files** e envie os arquivos desta pasta **individualmente na raiz** do repositório (não envie apenas o ZIP).
3. Faça o commit.
4. Em **Settings > Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
5. Após a publicação, abra https://rfboldrini.github.io/rdv-mackenzie/ no Safari do iPhone. Use **Compartilhar > Adicionar à Tela de Início**.

**Privacidade:** o código e os arquivos do aplicativo ficam públicos no GitHub Pages; os lançamentos e fotos inseridos no aplicativo ficam armazenados localmente no navegador do iPhone. Não insira dados pessoais diretamente nos arquivos publicados.

**Atenção:** a versão atual não possui exportação/importação de backup completo dos comprovantes. O CSV não contém fotos. Evite limpar os dados do Safari ou remover o app antes de guardar os PDFs e as fotos originais. A instalação e o fluxo de impressão precisam ser testados em um iPhone real.
